description: Map or extend a topic cluster (pillar + spokes + internal link plan)
argument-hint: <pillar topic, e.g. "AliExpress sales">

Build a topic cluster around: **$ARGUMENTS**

1. Inventory existing posts (`src/content/posts/`) that belong to this cluster;
   quote their slugs.
2. Design the cluster: ONE pillar page (broad keyword, calendar/guide style) +
   4–8 spoke posts (narrow long-tails). Mark which already exist vs. to-write.
3. Draw the link map explicitly: pillar → each spoke, each spoke → pillar +
   1–2 siblings. All targets must be real or planned slugs.
4. Present the map as a table (post · status: live/draft · links to). Ask which
   drafts to write; write them via the seo-blog-writing skill on approval.
